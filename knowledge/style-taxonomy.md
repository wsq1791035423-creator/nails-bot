# 03 款式图库：怎么放图、怎么打标签

> 图库质量决定推荐质量。一张图配 6 个标签，比你写 1000 字描述有用。

## 1. 放图

把图片直接丢进 `data/styles/` 目录，命名随意（建议 `001_雾霾蓝猫眼.jpg`，方便排序）。

- 支持 jpg / png / webp / jpeg
- 每张图尽量只拍**一只手或一双手的正面**，不要拼图、不要带太多水印
- 建议 30 张起步，覆盖下面 6 个色系各 5 张

## 2. 打标签

放好图后，二选一：

**Word（推荐，打字顺手）**

```bash
python scripts/make-sheet-docx.py
# 打开 data/styles/_标注表.docx，在每张图的冒号后面填
python scripts/import-styles.py
```

Word 里的格式长这样，**别改成表格、别删字段行**：

```
【001_雾霾蓝猫眼.jpg】
款式名：雾霾蓝猫眼
主色系：蓝绿
风格：猫眼
长度：短
显白度：显白
场合：日常,通勤
适合手型：都可以
需要延长：不需要
难度：低
```

**Excel（要下拉框、怕填错词的时候用）**

```bash
python scripts/make-sheet.py
# 填 data/styles/_标注表.xlsx
python scripts/import-styles.py
```

两个文件都在时，谁新用谁（脚本会打印读了哪个）。

**必填 5 项：**

| 字段 | 选什么 | 为什么重要 |
| --- | --- | --- |
| 款式名 | 自己起，如「雾霾蓝猫眼」 | 推荐时直接说这个名字 |
| 主色系 | 单选 | 对应「显白吗」「适合什么肤色」 |
| 风格 | 多选，逗号分隔 | 决定加价项，也决定用户怎么搜 |
| 长度 | 单选 | 短甲客人不该被推荐长甲款 |
| 显白度 | 单选 | 这是美甲客人第一关心的问题 |

**选填：**场合、适合手型、需要延长、难度、备注。

## 3. 受控词表（只能用这些词）

### 主色系（单选）
`裸色系` `粉调` `红调` `蓝绿` `紫调` `黑白灰` `金属` `多色` `透明`

### 风格（多选）
`纯色` `猫眼` `法式` `晕染` `渐变` `手绘` `贴钻` `波点` `腮红` `魔镜粉` `浮雕` `醋酸` `卡通`

### 长度（单选）
`短` `中` `长` `延长`

### 场合（多选）
`日常` `通勤` `约会` `婚礼` `拍照` `节日` `蹦迪`

### 显白度（单选）
`显白` `一般` `挑肤色`

### 适合手型（多选）
`手指短` `手指长` `手细` `手粗` `关节明显` `都可以`

### 需要延长（单选）
`不需要` `建议延长` `必须延长`

### 难度（单选）
`低` `中` `高`

## 4. 风格 → 加价项的自动映射

选了风格，导入时自动挂上对应加价项，不用你填价格：

| 风格 | 对应加价项 |
| --- | --- |
| 纯色 / 猫眼 | 无（已含在基础价） |
| 法式 / 波点 / 腮红 / 渐变 / 晕染 | S2 |
| 手绘 | S3（备注写「复杂」则 S4） |
| 卡通 | S5 |
| 贴钻 / 浮雕 / 醋酸 | S6 |
| 魔镜粉 | S7 |

## 5. 标签不求完美

先按直觉填。跑起来之后，真实对话会告诉你哪张图被反复推荐、哪张从来没人点——那时候再调标签。**第一版目标是能用，不是准确。**
