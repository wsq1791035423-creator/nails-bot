## 一、2026 流行趋势

来源：Marie Claire 美丽佳人（2026-05-27）整理。**趋势只是参考，最后要落到"做得出来、适合她"。**

### 热门款式

| 款式 | 一句话说明 | 适合谁 |
| --- | --- | --- |
| 亮片晕染 | 渐变底 + 细闪，像雾面光影，不铺满 | 想要低调有光、不想太闪 |
| 猫眼线条 | 极简线条 + 猫眼光带，韩系 | 通勤、极简党 |
| 玻璃美甲 | 通透折射感，靠层次堆出来 | 想要干净精致 |
| 碎钻 | 细碎小钻，安全不夸张 | 第一次做、怕夸张 |
| 韩系法式 | 留白 + 微闪，线条细 | 日常、婚礼 |
| 花园系 | 花瓣、植物、手绘 | 喜欢温柔浪漫 |
| 鹿纹 | 棕色 + 波点，比豹纹软 | 秋冬、显白 |
| 紫藤花 | 浅紫垂坠线条，修饰肤色 | 春夏、显白 |
| 珍珠项链 | 小珍珠排列，轻奢 | 婚礼、正式场合 |
| 天鹅绒 | 大面积柔光，像丝绒 | 秋冬、气质款 |
| 金属珠珠 | 立体小珠，有饰品感 | 想要设计感 |
| 星球 | 蓝紫/墨绿 + 亮粉晕染 | 通勤也能驾驭的深色系 |

### 流行色

- **云舞白**（2026 年度色）：白色但讲究层次，不是死白
- **裸色系**：珍珠白、奶茶裸、透感果冻色，最百搭
- **薄荷绿**：冷调浅绿，不荧光，显干净
- **桃粉**：粉橘之间，提气色、修饰肤色
- **莓果色**：蔓越莓/蓝莓那种，饱和但显白
- **马卡龙色**：低饱和高明度，年轻
- **金蓝 / 银色**：轻奢、冷感

### 怎么用

- 客人问"今年流行什么" → 挑 3–5 个说，别一次报全部
- 客人说"想要流行款" → 薄荷绿、桃粉、云舞白最稳
- 客人手偏黄 → 优先紫藤花、莓果色、深蓝这类冷调

## 二、显白配色原理（通用）

1. **冷调 > 暖调**：黄黑皮选蓝、紫、灰、冷粉，比橙、黄、正红安全
2. **低饱和 > 高饱和**：雾霾蓝、豆沙、裸粉 比 荧光绿、正黄 安全很多
3. **深色能压黄**：深蓝、墨绿、酒红、黑色，会让手显得白一档
4. **要避开的**：荧光色、正黄、正橙、过浅的裸色（会把手衬得发黄）
5. **光泽也有影响**：亮面更提亮，哑光高级但显手暗；黄皮优先亮面

> 一句话给客人：**"偏黄的话走冷调、低饱和，或者直接用深色压一压，最不容易翻车。"**

## 三、甲型与手型

### 甲型怎么分

| 甲型 | 长什么样 | 适合谁 |
| --- | --- | --- |
| 方 | 指尖一条平线，两侧直角，边缘锋利 | 手指细长、想显气场 |
| 方圆 | 指尖平，两个角磨圆 | 最百搭，绝大多数人不出错 |
| 圆 | 指尖是圆弧，指甲不长 | 短甲、学生、干活多的人 |
| 杏仁 | 两侧往里收窄，指尖圆弧收尖，像杏仁 | 显手长、优雅，最受欢迎 |
| 尖 | 比杏仁更窄更尖 | 长甲、欧美风、拍照 |
| 梯形 | 指尖比甲根宽，往外扩 | 个性、夸张风格 |

**杏仁和尖最容易混**：杏仁是柔和的收尖，尖甲是明显的尖锐。

### 手型配甲型

| 手的情况 | 建议甲型 | 原因 |
| --- | --- | --- |
| 甲床短宽 | 方圆 / 椭圆 | 尖甲会显得更短 |
| 甲床长窄 | 杏仁 / 尖 | 更优雅 |
| 手指短 | 中长甲 + 浅色 | 视觉拉长 |
| 手指粗 | 杏仁甲 | 收窄 |
| 关节明显 | 方圆，别太短 | 短甲会暴露关节 |

## 四、术语（客人常问）

- **建构**：用结构胶在甲面做加厚定型，让甲面更平、更硬、不容易断
- **甲膜延长**：用甲膜材料延长，轻薄自然，适合甲床条件好的
- **高位半贴**：半贴甲片贴得靠上，延长效果好，但甲型偏饱满
- **浅贴延长**：贴得靠下，可以塑形收窄，最显瘦但最贵
- **前置处理**：卸甲 + 去死皮 + 打磨 + 湿处理
- **封层**：最后一道，决定光泽和耐磨

## 五、常见误区（客人爱问的）

| 客人说 | 怎么回 |
| --- | --- |
| "做美甲伤甲" | 正规卸除不伤，暴力抠、自己撕才伤 |
| "能维持一个月吗" | 一般 2–3 周，指甲会长出来有缝，这是正常的 |
| "卸甲可以自己撕" | 不行，会带掉甲面一层 |
| "甲油胶越厚越结实" | 太厚反而容易整片翘 |
